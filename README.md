# xmlslice

根据 XML 弹幕密度，从 MP4 里切出高能片段。

支持弹幕姬 / DanmakuFactory 这类录播 XML：每条弹幕是 `<d p="秒数,...">`，第一段就是相对视频开头的秒数。礼物、醒目留言和上船记录不计入密度。

## 环境

- Python 3.9+
- ffmpeg

macOS 安装 ffmpeg：

```bash
brew install ffmpeg
```

## 使用

在本目录执行，不需要额外安装依赖：

```bash
python3 -m xmlslice \
  -x "弹幕.xml" \
  -v "录像.mp4" \
  -d 60 \
  -n 3 \
  -m 50 \
  --overlap 30 \
  --step 1
```

| 参数 | 含义 | 默认 |
|---|---|---|
| `-x` | XML 弹幕 | 必填 |
| `-v` | MP4 视频 | 必填 |
| `-d` | 普通模式每段时长（秒） | 60 |
| `-n` | 最多切几段。自动模式未设置 `-m` 时，按密度取前几段 | 1 |
| `-m` | 至少多少条弹幕才切片。自动模式可不填 | 普通模式为 1，自动模式不填 |
| `--auto` | 按弹幕数量自动决定每段时长 | 关闭 |
| `--overlap` | 片段之间允许的最大重叠（秒） | 30 |
| `--step` | 滑动窗口步长（秒） | 1 |
| `-o` | 输出目录 | 与视频同一目录 |

不够 `-m` 条弹幕的窗口会被跳过。若高密度片段不足 `-n` 段，只切满足数量的那些；一段都没有时不会切片。

自动模式加 `--auto`。统计窗口是 `xmlslice/density.py` 里的 `UNIT_SECONDS`，当前为 10 秒。片段只覆盖达标的这些窗口。

设置了 `-m` 时：

- 接下来一个单位时间内达到 `-m` 的窗口会收进片段
- 低于 `-m` 不满 10 秒又再次达到时，两段合成一段

```bash
python3 -m xmlslice -x "弹幕.xml" -v "录像.mp4" --auto -m 50
```

不设置 `-m` 时，自动找出高密度片段，按每秒弹幕数从高到低排序，输出 `-n` 段：

```bash
python3 -m xmlslice -x "弹幕.xml" -v "录像.mp4" --auto -n 3
```

输出文件名形如 `123s_原视频名.mp4`，`123` 是片段在原视频中的起始秒数。切片使用 ffmpeg 流复制，不重新编码，起点会对齐到前一个关键帧，所以实际开头可能比计算时间略早。
